Group 2 Hotel Management System API

Version 1.0.0 | REST API Documentation

Base URL:

Overview

This API provides hotel management services and integrates with external services (taxi, restaurant, tour).

Services We Provide

Other groups can consume these services:

  • Hotel Management: Complete hotel booking system
  • User Authentication: Registration, login, session management
  • Room Availability: Real-time room availability checking
  • Booking Management: Create, view, cancel bookings

Services We Consume

We integrate with these external services:

  • Taxi Service: Group 4/8
  • Restaurant Service: Group 3/7
  • Tour Service: Group 1/5/9

Authentication

POST Register User
/api/auth/register

Register a new user in the system.

Request Body

Parameter Type Required Description
email string Yes User email address
password string Yes Password (min 6 chars)
name string Yes Full name
role string No User role (customer, tour_guide, manager, admin)

Example Request

{ "email": "user@example.com", "password": "password123", "name": "John Doe", "role": "customer" }
POST Login
/api/auth/login

Authenticate user and create session.

Example Request

{ "email": "user@example.com", "password": "password123" }
GET Check Session
/api/auth/session

Get current user session information.

Hotel Management

GET List Hotels
/api/hotels

Get list of all hotels with filtering options.

Query Parameters

Parameter Type Description
city string Filter by city
min_price number Minimum price per night
max_price number Maximum price per night
amenities string Comma-separated amenities
GET Get Hotel Details
/api/hotels/{id}

Get detailed information about a specific hotel.

GET Get Hotel Rooms
/api/hotels/{id}/rooms

Get all rooms for a specific hotel.

Query Parameters

Parameter Type Description
check_in date Check-in date (YYYY-MM-DD)
check_out date Check-out date (YYYY-MM-DD)

Booking Management

POST Create Booking
/api/bookings

Create a new hotel booking.

Request Body

Parameter Type Required Description
hotel_id integer Yes Hotel ID
room_id integer Yes Room ID
check_in_date date Yes Check-in date (YYYY-MM-DD)
check_out_date date Yes Check-out date (YYYY-MM-DD)
adults integer Yes Number of adults
children integer No Number of children

Example Request

{ "hotel_id": 1, "room_id": 101, "check_in_date": "2024-12-25", "check_out_date": "2024-12-27", "adults": 2, "children": 1, "special_requests": "Late check-in if possible" }

Service Integration

GET Service Discovery
/api/services/discover

Discover available services and endpoints.

GET Check Service Status
/api/services/status

Check status of all integrated services.

Query Parameters

Parameter Type Description
service string Specific service to check (taxi, restaurant, tour, all)
POST Book External Service
/api/services/book

Book taxi, restaurant, or tour service.

Request Body

// Book Taxi { "service": "taxi", "data": { "pickup_location": "Hotel XYZ", "destination": "Bole Airport", "passengers": 3, "vehicle_type": "standard" } } // Book Restaurant { "service": "restaurant", "data": { "restaurant_id": 5, "date": "2024-12-25", "time": "19:30", "guests": 4 } } // Book Tour { "service": "tour", "data": { "tour_id": 3, "date": "2024-12-26", "participants": 2 } }
